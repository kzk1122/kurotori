# kurotori

画像の黒い枠（黒フチ）を自動でトリミングするブラウザツールです。

## 使い方

`index.html` をブラウザで直接開くだけで動作します。サーバー不要・インストール不要です。

```bash
open index.html
```

## 機能

- **ドラッグ＆ドロップ** または クリックで画像を読み込み
- **しきい値** スライダーで「黒」と判定するRGB値を調整（0〜100）
- **パディング** スライダーでトリミング後の余白を追加（0〜50px）
- **出力形式** を選択可能：AUTO / JPEG / WebP / PNG
- **ファイルサイズ比較** で元画像との差分を表示
- AUTO モードでは出力が元ファイルより大きくなる場合に品質を自動調整

## 対応フォーマット

JPEG / PNG / WebP / GIF / BMP / AVIF / TIFF / ICO / SVG
